# 导入弹窗键盘焦点复现截图

对应 Stronghold Protocol 0.2.1 / dev c2a2ef778cf728ff29b953b9842b2a39b1e9cbea。

## 操作

大厅打开干员调配，保持默认隐现、MAR-X、已调整 0。打开导入，点击空文本框，按 Shift+Tab、Enter，再取消导入并刷新重开。

## 原始截图

- before/01：打开空导入窗口。
- before/02：按键后窗口仍打开，提示当前已有 1 名调配；背景不装备被激活。
- before/03：取消后已调整 1、已同步，隐现为不装备。
- before/04：刷新重开仍显示已调整 1。模块仍为 none 由本地观察记录确认，该图不单独展示模组选项。
- after/01：修复后打开即聚焦文本框。
- after/02：相同步骤后焦点在窗口内选择文件，背景保持默认；文件选择器已取消。
- after/03：取消导入后已调整 0，MAR-X 保持默认。
- after/04：刷新重开后仍保持默认。

截图来自真实本地页面，使用项目未安装可选美术时的回退显示。仅执行正常点击、按键和鼠标滚轮；没有修改截图像素、移除遮罩或向页面注入配置。图片不能独立展示按键顺序，请结合上述步骤阅读。
